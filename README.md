# GeoAlarm 📍🔔

**GeoAlarm** is a location-based alarm application built with Flutter that allows users to set alarms based on geographical locations rather than specific times. Instead of ringing at a scheduled hour, GeoAlarm automatically alerts users when they arrive at or leave a selected destination.

The application is designed to make travelling and commuting easier by helping users avoid missing their destinations. Users can select starting points and destinations, monitor their journeys on an interactive map, track remaining distances, and receive audible alerts when they reach their specified locations.

### Key Features
- 📍 **Location-Based Alarms:** Set alarms using specific geographical locations.
- 🗺️ **Interactive Maps:** Visualize selected locations and monitor journeys.
- 🚗 **Journey Tracking:** Track movement from a starting point to a destination.
- 📏 **Distance Monitoring:** View route distances and remaining distance to your destination.
- 🔔 **Arrival & Departure Alerts:** Configure alarms to trigger when arriving at or leaving a location.
- 🔊 **Persistent Alarm Sound:** Repeated audible alerts to ensure users notice notifications.
- 💾 **Alarm Persistence:** Saved alarms remain available even after closing and reopening the application.
- 📐 **Customizable Alert Radius:** Set the distance radius within which an alarm should be triggered.

### Built With
- Flutter & Dart
- Geolocator
- Flutter Map
- LatLong2
- Shared Preferences
- Audio Players
- Flutter Local Notifications

### Project Goal
GeoAlarm aims to provide a smarter and more convenient way of managing location-based reminders, particularly for commuters, travellers, students, and anyone who wants to be alerted when approaching or leaving a particular destination.
